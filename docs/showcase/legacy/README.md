# Output Showcases

This folder persists example outputs generated by real runs so the repository can demonstrate how different rendering profiles look without rerunning the research workflow.

## Demo deck

[`demo.md`](./demo.md) — 30-minute live presentation. Built with [Marp](https://marp.app/).

Covers agentic design patterns as a central section, real adversarial critique output from the localstack-alternatives showcase run, score progression with the iter-7 dip explained, all three output styles (`default` / `paper` / `technical_doc`), trust + reproducibility, and a presenter runbook in HTML comments. Slide timing budget annotated per section.

The loop diagram (`loop.svg`) is pre-rendered from `loop.mmd` using [Mermaid CLI](https://github.com/mermaid-js/mermaid-cli). Marp CLI does not execute JavaScript at render time, so Mermaid code blocks won't work in exported files — pre-rendered SVG is the correct approach.

To regenerate the diagram after editing `loop.mmd`:

```bash
mmdc -i docs/showcase/loop.mmd -o docs/showcase/loop.svg -b transparent
```

To render the deck:

```bash
# HTML — best for screen recording (self-contained, no server needed)
npx @marp-team/marp-cli --allow-local-files docs/showcase/demo.md --html -o docs/showcase/demo.html

# PowerPoint
npx @marp-team/marp-cli --allow-local-files docs/showcase/demo.md -o docs/showcase/demo.pptx

# PDF
npx @marp-team/marp-cli --allow-local-files docs/showcase/demo.md --pdf -o docs/showcase/demo.pdf
```
